# Taxonomias de tema por nicho

Usadas por `scripts/extrai.py --nicho <nome>`. A ordem importa: a primeira regra que casar vence, então o tema mais específico vem antes do mais genérico.

Para criar um nicho novo, copiar o bloco em `extrai.py` (dicionário `NICHOS`) e ajustar. Sempre terminar com `Institucional / marca`.

## Pegada do vídeo (vale para todos os nichos)

Classificação por copy + capa, nesta ordem de prioridade:

1. **Depoimento de paciente**: o paciente fala (aspas, @ do paciente, relato em 1ª pessoa de quem tratou)
2. **Caso real / antes e depois**: o profissional narra um caso ("essa paciente", "atendi", "foram implantadas")
3. **Oferta / promoção / pacote**: mês temático, brinde, clube, vagas limitadas, valores especiais
4. **Quebra de objeção / mito**: "não é bem assim", "mito ou verdade", desarma medo
5. **Emocional / storytelling**: história pessoal, série, família, autoestima
6. **Tecnologia / equipamento**: o aparelho é o protagonista
7. **Didático / explicativo**: aula direto para a câmera
8. **Institucional / convite**: peça curta, só chama para agendar

**A capa manda mais que a copy.** Sempre olhar a folha de contato antes de fechar a leitura: tela dividida, profissional em cena, arte estática e legenda queimada só aparecem na imagem.
