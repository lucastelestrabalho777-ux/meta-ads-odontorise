# Tom do documento

O documento é apresentado pelo gestor **ao cliente final** (o dentista, a clínica). Ele lê sozinho, sem ninguém traduzindo.

## Como tratar o cliente

Terceira pessoa: **"a Dra. Loliane"**, **"a Clínica Vitalle"**, **"a clínica"**. Nunca "você", nunca "nosso cliente", nunca "a conta".

## Traduções obrigatórias

| Não escrever | Escrever |
|---|---|
| leilão, disputar leilão | disputa pelos mesmos pacientes |
| CTWA, click-to-whatsapp | anúncio que abre conversa no WhatsApp |
| verba, budget, investimento diário | investimento |
| custo por conversa, CPL, CPA | custo por paciente que chega |
| criativo | anúncio, vídeo, peça |
| boost, impulsionamento de post | impulsionamento de publicação |
| conjunto, campanha, ABO/CBO | (não citar, é estrutura interna) |
| público frio/quente, remarketing | quem ainda não conhece a clínica / quem já teve contato |
| conversão, lead | contato, paciente interessado |
| a conta está 38% em lentes | a clínica concentra os anúncios em lentes |

## O que nunca entra no documento

- Nome do gestor ou da agência nas justificativas ("recorte definido com o Lucas")
- Decisões internas da conta (rebalanceamento, pausa de anúncio, valor investido)
- Concorrente que também é cliente da agência: **retirar em silêncio** e avisar o gestor no chat
- Quem foi excluído do recorte e por quê, se o motivo expõe critério interno
- Ressalvas técnicas de coleta (limite do scraper, URL que falhou, thumb que não baixou)

Tudo isso vai para o gestor **no chat**, nunca no arquivo.

## Como escrever os achados

Cada achado abre com o número e diz o que ele significa para a clínica, não para a campanha.

- ❌ "96 anúncios levam para o perfil do Instagram, o que indica boost de post sem otimização para conversa"
- ✅ "Quase metade dos anúncios da região leva para o perfil do Instagram, não para uma conversa. Boa parte dos concorrentes está usando anúncio para ganhar seguidor, não para agendar consulta."

Frases curtas. Sem ironia sobre concorrente. Sem promessa de resultado. Sem adjetivo vazio ("incrível", "poderoso").

## Rodapé

Fonte, data da coleta, critério do levantamento (região e especialidade) e a nota de que só entram anúncios ativos no dia. Nada além disso.
